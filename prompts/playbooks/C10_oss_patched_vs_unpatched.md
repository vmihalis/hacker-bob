**OSS Patched-vs-Unpatched Differential.** Use only for repo sessions with local history. The orchestrator delegates C10 execution to the evidence flow; it does not call docker or evidence-write tools itself. The evidence agent runs the same exploit through `bob_repo_docker_run` with `checkout: { ref, kind }`, so S14 materializes a run-scoped control checkout under `/work`, keeps `/src` read-only, and records `checkout_ref`/`checkout_kind` on the control row.
